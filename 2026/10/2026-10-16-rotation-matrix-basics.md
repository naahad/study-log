# 2026-10-16 — 회전행렬 기초 (2D 화살표에서 SO(3)까지)

**주제**: Modern Robotics 3.2절의 회전행렬을 2D "앞쪽·왼쪽 화살표"로 다시 쌓아 올리기

> 자료: Modern Robotics (Lynch & Park) 1장 Preview(책 p.1–8), 3.2.1절(책 p.66–70, PDF p.86–90)
> 진행: `/university teach 회전행렬` → 3장 설명에서 막혀서 1장부터 다시 시작 → 튜터 질문으로 단계별 확인

## 핵심 개념

1. **자유도(dof)**: 로봇(강체)의 상태를 완전히 나타내는 데 필요한 숫자 개수.
   평면 강체는 3개 `(x, y, θ)`, 공간 강체는 6개 (위치 3 + 방향 3). 방향 θ도 상태의 일부라서
   위치가 같아도 보는 방향이 다르면 다른 상태다. (책 p.3)

2. **회전행렬의 각 열 = 로봇 축 화살표를 바닥(고정) 좌표계로 쓴 것**
   ```
   θ일 때 앞쪽 화살표 = (cos θ, sin θ),  왼쪽 화살표 = (-sin θ, cos θ)

            앞쪽     왼쪽
   R  =  [ cos θ   -sin θ ]
         [ sin θ    cos θ ]

   θ = 90°  →  R = [ 0  -1 ]
                   [ 1   0 ]
   ```

3. **회전행렬의 조건 (SO(2), SO(3))**
   | 조건 | 식 | 뜻 |
   |---|---|---|
   | 각 열 길이 1 + 열끼리 직각 | `R^T R = I` | 늘거나 찌그러지지 않음 |
   | 오른손 좌표계 | `det R = 1` | 거울상(좌우 반전) 제외 |
   - `R^T R`의 (i, j) 칸 = R의 i열 · j열 (내적). 대각선 = 길이², 나머지 = 직각이면 0.
   - 2×2 행렬식: `det [a b; c d] = ad − bc`
   - `R^-1 = R^T` (역회전은 전치만 하면 됨)
   - SO = Special(det = 1) Orthogonal(R^T R = I). "R ∈ SO(3)" = "R은 회전행렬이다". (책 p.68 Def 3.1–3.2)

4. **오른손 좌표계**: 오른손 엄지 = x(앞), 검지 = y(왼쪽), 중지 = z(위).
   책에서는 `x̂ × ŷ = ẑ`로 씀 (책 p.67). ROS 로봇 좌표계도 x 앞 · y 왼쪽 · z 위 (REP 103 — 원문 미확인, 2주차에 확인).

5. **좌표계 바꾸기 = 행렬 × 벡터 = 열의 가중합**
   로봇이 θ = 90°(+y 방향을 봄)일 때, 로봇 기준 "앞 1m, 오른쪽 1m"의 컵:
   ```
   p_b = (앞 1, 왼쪽 -1) = (1, -1)
   R × p_b = 1 × (0, 1) + (-1) × (-1, 0) = (1, 1)    ← 바닥 기준 위치
   ```
   책 p.70 예제 `R_b × (1, -1, 0) = (1, 1, 0) = p_a`와 같은 계산 (z만 추가).
   회전행렬의 세 용도 중 ② "기준 좌표계 바꾸기"에 해당.

## 판정 연습
```
R = [ 0  1 ]     R^T R = I  → 조건 ①② 통과
    [ 1  0 ]     det R = 0·0 − 1·1 = −1  → 거울상, 회전행렬 아님
```

## 막혔던 점과 해결
- **3장 설명을 처음부터 따라가지 못함** → 원인은 행렬 기호(`R^T`, `I`, `det`, 행렬곱)가 낯설었던 것.
  2D 화살표 두 개로 행렬을 직접 만들고, 기호를 하나씩 풀어서 해결.
- **로봇 기준 → 바닥 기준 변환을 혼자 시작하지 못함** → "로봇의 앞 = 바닥의 어느 쪽?"
  "로봇의 오른쪽 = 바닥의 어느 쪽?"으로 쪼개니 바로 (1, 1)을 구함.
- `R^T R = I`를 `= 1`로 씀 → 결과는 숫자가 아니라 단위행렬.
- 터미널의 LaTeX 수식이 읽기 어려움 → 평문·ASCII 행렬로 설명.
