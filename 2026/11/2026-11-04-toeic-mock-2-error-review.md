## 이어서 (22:05)

### 주제
Floor Field 원 논문 ② Kirchner & Schadschneider (2002), 3.1절: 단계 3(k_S·k_D, Fig.5·6), 단계 4(δ·α, Fig.7·8, 세 영역), 단계 5(파라미터 표)를 마쳤다. 단계 6(책 덮고 말하기)은 질문만 내놓았고 다음에 답한다.

### 핵심 개념
1. **k_S와 k_D**: k_S는 출구를 얼마나 잘 아는지, k_D는 사람을 얼마나 따라가는지를 나타낸다. k_S가 0이면 random walk, 크면 최단 경로로 거의 결정적으로 움직이고 T는 최솟값으로 수렴한다.
2. **T(k_D)는 단조롭지 않다 (Fig.5(b))**: 작지만 0이 아닌 k_D에서 T가 최소가 된다(minimal intelligence). 더 키우면 T가 늘어나 최댓값에 포화한다. 이 효과는 k_S ≈ 0.4에서 가장 뚜렷하고, k_S ≈ 10에서 약하며, k_S = 0.1에서 사라진다.
3. **α(확산)**: ρ = 0.3에서는 α가 클수록 모든 k_D에서 T가 늘어난다. 발자국이 빨리 번져 묽어지면 잡음이 되기 때문이다. ρ = 0.003에서는 막힘이 거의 없어 오히려 T가 줄어든다 (Fig.8).
4. **δ(감쇠)**: 효과가 k_D에 따라 뒤집힌다. 작은 k_D에서는 δ가 작을수록 T가 짧고, 큰 k_D에서는 δ가 작을수록 T가 길다. 곡선은 k_D ≈ 1 근처에서 교차한다 (Fig.7(b)).
5. **세 영역 (p.11)**: ordered(k_S 큼, k_D 아주 작음), disordered(k_S 작음, k_D 큼), optimal(k_S 중간, k_D 작지만 0은 아님).

### 그래프 눈금으로 읽은 값 (근사)
```txt
Fig.5(b)  k_S=0.4 : k_D=0 약 4370 → 최소 약 4290 → 포화 약 6400
          k_S=1.0 : 약 3020 → 포화 약 3800
          k_S=10  : 약 2230 → k_D=10에서 약 2490
Fig.7(a)  포화    : α=0.3 약 6400 / α=0.1 약 5800 / α=0.0 약 5300
Fig.7(b)  포화    : δ=0.2 약 6600 / δ=0.3 약 5300 / δ=0.4 약 4730
Fig.8     δ=0.2, α 0→1 : ρ=0.3 약 4030→4590 / ρ=0.003 약 546→524
```

### 막혔던 점과 해결
- **k_D가 너무 크면 왜 T가 늘어나는가**: 처음에 "panic"이라고 답했는데 이는 상태의 이름이었다 → 식 (1)로 돌아가 "S보다 D를 더 보게 되어 출구로 못 간다"로 다시 썼다.
- **기호 구분**: "k_S보다 D"라고 썼다 → 지도 값끼리(S·D), 민감도끼리(k_S·k_D) 비교한다.
- **작은 k_D에서 δ가 작을수록 좋은 이유**: herding 효과만 말하고 δ와 연결하지 못했다 → δ가 작으면 발자국이 오래 남아, 작은 k_D에서 부족한 정보를 보완한다.
- **optimal의 크기를 어떻게 표현하는가**: p.11·p.9 원문을 해석해 확인했다. 원문은 경계 수치 없이 상대적인 말(중간, 작지만 0은 아님)만 쓴다.
- **optimal의 T는 전체 최소가 아니다 (Claude 설명 정정)**: 처음에 "T가 최소"라고 설명했지만, Fig.9에서 T는 모든 밀도에서 ordered < optimal < disordered다. k_S가 정해졌을 때 k_D로 얻는 최소로 해석했다 (Claude 추정, 원문에 그대로 적혀 있지는 않다).
- **원문 오타**: p.8 본문은 Fig.5(b)도 "fixed k_D and variable k_S"라고 적었지만, 그래프와 캡션을 보면 k_S 고정, 가로축 k_D다.
