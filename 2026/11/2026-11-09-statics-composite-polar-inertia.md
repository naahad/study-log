# 2026-11-09 · 정역학 ④ 복합 단면 관성모멘트(T·I자) · 극관성모멘트·회전반경

> 편입 준비(최상위 계획) 역학. 경북대 자료조서·구술, 충남대 면접 대비. 교재는 Hibbeler Statics 14판 SI이며, 오늘 설명은 튜터 세션 내용으로 교재 본문과 대조하지 않았다.

## 주제
직사각형 조각으로 나눈 T자·I자 단면의 도심축 관성모멘트를 표로 구했다. 이어서 점에 대한 극관성모멘트 J = Ix + Iy와 회전반경 k = √(I/A)를 배우고 원 단면에 적용했다.

## 핵심 내용
1. **복합 단면 4단계**: ① 전체 도심 ȳ = Σ(A·y) / ΣA → ② 조각별 자기 도심축 I_own = b·h³/12 → ③ 조각별 d = |y − ȳ|, A·d² → ④ I = Σ(I_own + A·d²).
2. **b와 h 구분**: b는 축과 나란한 변, h는 축에 수직인 변. 같은 넓이라도 h가 세제곱으로 들어가서, 축에 수직으로 길게 퍼진 조각의 I가 훨씬 크다.
3. **대칭 활용**: 위아래 대칭인 I자는 ȳ를 계산 없이 높이의 절반으로 잡는다. 웹 도심이 전체 도심과 겹치면 d = 0이라 A·d² 항이 없다. 플랜지는 자기 I가 작아도 축에서 멀어 A·d²로 큰 값을 얻는다.
4. **극관성모멘트**: 점 O 기준. `J = ∫ r² dA = ∫ (x² + y²) dA = Ix + Iy` (같은 점에서 만나는 두 축). 축의 비틀림(재료역학 τ = T·ρ/J)에서 쓴다.
5. **회전반경**: `I = k²·A`, `k = √(I/A)`. 넓이 전체를 축에서 k 거리에 모았을 때 같은 I를 주는 거리. 단위는 길이. 동역학 질량 관성모멘트 I = m·k²로 이어진다.

## 예제
```txt
[T자] 플랜지 60×20 (위), 웹 20×60 (아래), 바닥 y = 0
조각   A     y    I_own     d    A·d²
①    1200   70   40,000    20   480,000
②    1200   30   360,000   20   480,000
ȳ = (1200·70 + 1200·30) / 2400 = 50 mm
I = (40,000 + 480,000) + (360,000 + 480,000) = 1.36×10⁶ mm⁴
(웹 I_own이 플랜지의 9배: h 3배 → 27배, b 1/3 → 9배)

[I자] 위 플랜지 60×20 + 웹 20×60 + 아래 플랜지 60×20, 높이 100
대칭 → ȳ = 50
조각   y    d    I_own + A·d²
①     90   40   40,000 + 1,920,000 = 1,960,000
②     50    0   360,000 + 0         =   360,000
③     10   40   40,000 + 1,920,000 = 1,960,000
I = 4.28×10⁶ mm⁴

[극관성모멘트] 직사각형 60×20, 도심 O
Ix = 60·20³/12 = 40,000,  Iy = 20·60³/12 = 360,000 (세로축은 b·h가 바뀜)
J = 400,000 mm⁴

[원] 반지름 r,  J_O = π·r⁴/2
대칭 → Ix = Iy = J/2 = π·r⁴/4
kx = √(Ix/A) = √((π·r⁴/4) / (π·r²)) = r/2
```

## 막혔던 점과 해결
- T자에서 직사각형의 b와 h 중 어느 쪽인지 처음에 시작하지 못함 → "축과 나란한 변 / 축에 수직인 변" 선택지로 쪼개니 정답. 오후 극관성모멘트 세션에서 세로축 Iy는 처음부터 b·h를 바꿔 맞힘 (재발 없음).
- 조각별 I_own + A·d²를 더해 전체 I를 구하는 질문을 시작하지 못함 → 빈칸 식으로 쪼개니 정답. 질문 표현("기여하는 값")이 모호했던 탓도 있음.
- I자 표의 조각 도심 y 칸에 두께·높이(20, 60)를 씀 (d는 맞음) → 다시 물으니 90 · 50 · 10 정답. 비대칭 단면이면 ȳ부터 틀리는 실수라 주의.
