## 핵심 개념
1. **FBD 동그라미 규칙**: 점을 동그라미로 감싸고, 동그라미가 자르는 줄만 힘으로 그린다. 각 줄 = 점에서 멀어지는 방향의 장력 하나.
2. **줄 장력은 줄 끝 점(물체) 하나의 평형으로 정해진다.** 아래에 달린 무게를 모두 더한 값이 아니다. 마찰 없는 도르래를 지나는 줄은 장력이 어디서나 같다 (F3-5: T_EB = W_C).
3. **무게는 비스듬한 줄의 세로 성분이 받친다.** 받치는 식은 그 무게가 매달린 점의 ΣFy. 줄이 수평에 가까울수록 같은 무게를 받치는 데 장력이 커진다 (sin(각) → 0).
4. **점이 여러 개면 미지수가 2개 이하인 점부터** (평면 질점은 식 2개). 여러 점을 함께 감싸면 그 사이 줄은 내부력이라 그리지 않는다 (F3-6).
5. **3D 힘 벡터 = 크기 × 단위벡터**: F⃗ = F · û = F (r⃗_AB / r_AB). 각도 대신 좌표로 성분을 바로 얻는다. 3-4-5 비율도 단위벡터 성분이다.

## 예제 (F3-11 단위벡터)
```
r⃗_AB = −3î + 1.5ĵ + 1k̂      r_AB = √12.25 = 3.5 m
û_AB = −(6/7)î + (3/7)ĵ + (2/7)k̂     (36+9+4)/49 = 1 ✓
F⃗_B = F_B · û_AB
```

## 막혔던 점과 해결
- F3-2: sinθ까지 구하고 케이블 길이로 못 바꿈 → 이미 아는 변(보의 반 길이)과 삼각비.
- F3-4: 수평·수직 축으로 세워 F_N과 스프링 각이 엮임 → 경사면은 면에 평행·수직 축.
- F3-5: 링 E의 FBD에 C의 무게를 직접 넣음 → E에 닿은 줄은 ED·EB·EA뿐, C는 EB 장력으로 전달.
- F3-6: B·C를 묶은 FBD에 내부 장력 T_CB를 넣고 미지수 3개에 식 2개 → B부터 따로.
- 확인 질문에서 근거(세로 성분 증가)는 맞았는데 결론(A가 더 가벼워야)을 반대로 답함 → 세로 성분 = 무게를 받치는 힘으로 다시 연결. (원인: 입력창 자동 제안 문장을 그대로 씀 → 확인 질문엔 직접 답하기)

## 곁질문
- **유효숫자**: 처음 0이 아닌 숫자부터 센다 (0.283 → 3자리, 0.28 → 2자리, 0.250 → 3자리).
- **반올림 규칙 (Hibbeler 1장 수치 계산)**: 최종 답은 유효숫자 3자리, 중간값은 반올림하지 않고 마지막에 한 번만. 예: 1.5/cos20° × 2 → 먼저 반올림하면 3.20, 끝에 하면 3.19.
- **손글씨 벡터 표기**: 벡터는 화살표 F⃗, 크기는 그냥 F, 모자(^)는 단위벡터에만 (î, ĵ, k̂, û). ΣF⃗ = 0은 벡터식, ΣFx = 0 등은 스칼라식.
