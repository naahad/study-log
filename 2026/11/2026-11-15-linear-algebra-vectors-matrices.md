**주제**: 로봇 코스 0주차 ① (B0 · 편입 연계). 3Blue1Brown *Essence of Linear Algebra* 1–4장을 보고, 장마다 확인 문제를 손으로 풀었다.

## 핵심 개념
1. **벡터 = 원점에서 출발하는 화살표 = 숫자 목록.** 더하기는 화살표 이어 붙이기(v 끝에서 w 시작 → 원점에서 마지막 끝까지), 그래서 성분끼리 더한다. 스칼라배는 같은 직선 위에서 늘이기·줄이기 (음수면 방향 반대).
2. **기저 벡터**: (3, -2)는 "î를 3배 + ĵ를 -2배"라는 지시다 (선형 결합).
3. **행렬의 열 = î, ĵ가 옮겨 간 곳.** 변환 뒤에도 (x, y) = x·î + y·ĵ 관계가 그대로라서, î·ĵ가 간 곳만 알면 모든 벡터가 간 곳을 안다.
4. **행렬 × 벡터 = 열의 가중합**: x·(1열) + y·(2열).
5. **행렬곱 = 변환 이어 하기.** 오른쪽 행렬부터 적용한다 (함수 f(g(x))와 같음). 순서를 바꾸면 결과가 달라질 수 있다 (교환법칙 X).

## 예제 (손계산)
```
1장  v = (2, 1), w = (-1, 3)  →  v + w = (1, 4),  2v = (4, 2)
2장  (3, -2) = 3·î + (-2)·ĵ
3장  î → (1, -2), ĵ → (3, 0)

     M = |  1  3 |
         | -2  0 |

     M (-1, 2) = -1·(1, -2) + 2·(3, 0) = (-1, 2) + (6, 0) = (5, 2)

4장  R = 90° 반시계 회전,  S = 전단(shear)
     R = | 0 -1 |     S = | 1 1 |
         | 1  0 |         | 0 1 |

     먼저 R, 다음 S  →  S·R   (î → (0,1) → (1,1),  ĵ → (-1,0) → (-1,0))
     S·R = | 1 -1 |       R·S = | 0 -1 |
           | 1  0 |             | 1  1 |      → S·R ≠ R·S
```

## 이어서 (17:49) — 정역학 4.4 FP: 힘의 모멘트 (스칼라·벡터)

**주제**: 편입 역학. Hibbeler 정역학 14판 4.4 Fundamental Problems F4-1~12를 혼자 풀고 `/mech 4.4`로 채점했다. 12문제 중 8문제 맞음, 4문제 오답이다. 오답은 「역학 오답 노트」에 기록했고, 채점 후 직접 고쳤다.

### 핵심 개념

1. **2차원 모멘트 = 성분별 Fd의 합 (모멘트의 원리, Varignon)**: 힘을 x·y 성분으로 나누고 각 성분 × O에서 그 성분 작용선까지의 수직 거리를 부호와 함께 더한다. 반시계를 +로 잡고, 결과가 음수면 시계 방향이다.
2. **막대 방향으로 분해하기**: 힘을 막대 축과 그 수직 방향으로 나누면 수직 성분 × 막대 길이로 바로 풀린다. 이때 필요한 것은 "힘과 막대 사이 각"이다.
3. **3차원 모멘트 M_O = r × F**: r은 O에서 힘의 작용선 위 아무 점까지의 벡터다. 행렬식 i(…) − j(…) + k(…)로 펼친다.
4. **단위**: 거리를 mm로 넣으면 결과는 N·mm이고, 1000으로 나눠야 N·m가 된다.

### 막혔던 점과 해결 (채점 결과)

```txt
맞음 8: F4-1, 2, 3, 6, 7, 8, 9, 10 (2차원 모멘트 팔·부호는 모두 맞음)
F4-4   식은 맞음 → 둘째 항 값을 10배 작게 계산 + N·mm를 kN·m로 표기     (계산)
F4-5   힘과 막대 사이 각을 55°로 잡음 (정답 50°, 그림의 20°·30°에서)     (각도)
F4-11  행렬식 j 성분 앞의 − 누락 → j 부호 반대                          (부호)
F4-12  F4-11과 같은 실수, F1·F2 둘 다                                   (부호)
```

- 4문제 중 3문제가 계산·부호 실수였다. 3차원 외적 j 성분은 두 문제에서 같은 실수를 했다.
- 검산 방법: M = r × F는 r과 수직이므로 r·M = 0이어야 한다. 0이 아니면 부호를 다시 본다.
- 채점 직후 모두 직접 고쳤다. 다시 풀기는 다음 날 역학을 시작할 때 한다 (기억으로 푸는 것을 피하려고).

## 이어서 (22:55) — Floor Field 구현 ①: 정적 필드 셀 오토마톤·재현 검증

**주제**: 편입 Floor Field. 레포 [floor-field-evacuation](https://github.com/naahad/floor-field-evacuation)에 k_D = 0 기본 모델(정적 필드, 배제, 충돌 해결 mu = 0, 문 칸 제거)을 직접 짜고, Kirchner 2002 Fig.5(b)의 대피 시간을 재현했다. Claude는 단계 안내·힌트·리뷰만 했다.

### 만든 함수 (floorfield.py)
```txt
move_probs(p, S, walkable, occ, k_S)        한 사람의 5방향 이동 확률 (제자리, 상, 하, 좌, 우)
choose_targets(pos, S, walkable, occ, k_S, rng)  사람마다 rng.choice(5, p=probs)로 가려는 칸
resolve_conflicts(pos, targets, rng)       같은 칸을 고른 사람이 여럿이면 1명만 이동 (mu = 0)
step(pos, S, walkable, door, k_S, rng)     점유 → 목표 → 충돌 → 문 칸 도착자 제거
simulate(k_S, rho, seed, max_steps)        0명이 될 때까지 반복 → 대피 시간 T
```

### 핵심 개념
1. **이동 확률** p = N · exp(k_S · S) · (1 − n) · ξ. 이웃 5칸 좌표를 `p + MOVES`로 만들고, 그 좌표로 S·walkable·occ에서 5개씩 꺼내 곱한다.
2. **제자리 예외**: 자기 칸은 occ가 True라서 그대로 쓰면 제자리 확률이 항상 0이 된다. "비어 있음" 배열을 `~occ_nb`로 만든 뒤 0번(제자리)만 True로 덮는다.
3. **넘침 방지**: exp 안에 `S_nb − S_nb.max()`를 넣는다. 정규화하면 확률은 같고, 가장 큰 칸이 항상 1이라 합이 0이 되지 않는다 (방 전체 최댓값을 빼면 먼 칸에서 전부 0이 될 수 있음).
4. **충돌 해결 (mu = 0)**: 딕셔너리로 "가려는 칸 → 사람 번호 목록"을 모으고, 2명 이상인 칸만 `rng.choice`로 승자 1명을 남기고 나머지는 제자리. 점유는 스텝 시작 기준이고 사람 있는 칸은 확률 0이라 충돌은 빈칸에서만 난다.
5. **k_S = 10에서 T = 2N + 1**: 문 앞에 줄이 생기면 문 칸 하나가 2스텝에 1명씩만 내보낸다 (문 아래 칸이 이번 스텝에 비어도 다음 사람은 다음 스텝에야 들어옴). 이 조건의 T는 출구 처리량이 정한다.

### 재현 결과 (rho = 0.3, 1116명, 시드 0~2)
```txt
k_S    논문 (Fig.5(b))   결과 평균   각 시드              차이
10     약 2230           2233        2233, 2233, 2233     +0.1%
1      약 3020           3062        3091, 3043, 3051     +1.4%
0.4    약 4370           4309        4396, 4210, 4320     -1.4%
```
k_S가 클수록 T가 작아지는 순서도 같다. 실행 시간은 k_S = 10 1회 약 100초, 0.4 1회 3~4분.

### 막혔던 점과 해결
- **제자리 예외 배열을 0에서 시작** → occ를 안 봐서 제자리만 남고 4방향이 0. `~occ_nb`에서 시작해 0번만 덮도록 고침.
- **`nb[nb[:, 0], nb[:, 1]]`** → 좌표 배열을 자기 값으로 인덱싱해 `IndexError: index 31 is out of bounds for axis 1 with size 2`. 행·열 나누기는 `ni, nj = nb.T`(전치 후 두 변수로 풀기)면 된다.
- **반환값을 받지 않음 (3번)**: `print(move_probs)`(함수 자체 출력), `move_probs(...)` 결과 버림, 테스트에서 `step(pos, ...)`만 호출해 10스텝 내내 1116명. → "함수가 return하면 `=`로 받는다".
- **충돌 해결에서 승자를 버림** → 충돌 칸에서 전원 제자리 (mu = 1처럼 동작). "겹치는 칸 없음" 테스트로는 못 잡았고, "움직인 사람 수 = 서로 다른 목표 칸 수" 테스트로 잡음 (고치기 전 628, 후 695).
- 10스텝으로는 맞는지 판단 불가 (2명만 나감) → 300스텝, 50스텝마다 출력.
- 변수명 짓기가 어려움 → 이웃 5칸은 `_nb`, 정규화 전 `w` / 후 `probs`, 사람 번호 `n`·`m` (좌표 `i`, `j`와 구분).
