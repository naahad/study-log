**주제**: Hibbeler 동역학 12.4–12.6 곡선 운동(직교좌표 성분)·포물선 운동을 `/univ teach`로 배우고 확인 질문 5개로 점검. (`/next 동역학`을 실행하면 teach가 바로 시작되도록 /next 스킬도 바꿈)

### 핵심 개념
1. **곡선 운동 = x 직선 운동 + y 직선 운동**: r = x i + y j, v = vx i + vy j (vx = dx/dt), a = ax i + ay j. 속력 v = √(vx² + vy²).
2. **v는 경로에 접선, a는 접선이 아님** (12.4): 포물선 꼭대기에서 v는 수평, a는 연직 아래로 서로 90°.
3. **포물선 운동**: ax = 0이라 vx = (vx)0로 일정, ay = −g라 y는 등가속도 공식 3개에 a = −9.81 m/s².
4. **풀이 순서**: 처음 속도 성분 분해 ((vx)0 = v0 cosθ, (vy)0 = v0 sinθ) → 한 방향(보통 y)에서 t → 그 t를 x에. x와 y를 잇는 것은 시간 t뿐.

### 예제 (세션에서 푼 것)
- 평지에서 20 m/s, 30°: (vx)0 = 17.32, (vy)0 = 10 m/s → 0 = 10t − 4.905t², t = 2.039 s → x = 35.3 m. 꼭대기에서 vx = 17.32 m/s, vy = 0, a = g 연직 아래.
- 20 m 옥상에서 수평 10 m/s: −20 = −4.905t², t = 2.019 s → R = 20.19 m.
- 20 m 옥상에서 20 m/s, 위쪽 30°: 0 = 20 + 10t − 4.905t² → t = 3.281 s (다른 해 −1.243 s). 착지 vy² = 10² + 2(9.81)(20) → vy = −22.19 m/s.

### 막혔던 점과 해결
- 꼭대기에서 vx = 0이라고 답함 → "ax = 0이면 vx가 변하나?"로 쪼개니 17.32 m/s 그대로라고 바로 고침. 0이 되는 건 vy뿐.
- 위가 +인데 식을 −20 = ½(9.81)t²로 적음 (t 값은 맞음, 옮겨 적다 실수). 위가 +면 a = −g를 식에 그대로 넣기.
- 착지 속도를 제곱근으로 구하면 크기만 나옴 → 내려오는 중이니 vy = −22.19 m/s로 부호를 붙여야 함.
- 2차방정식 음수 해: "시간은 음수일 수 없다"에 더해, 포물선을 거꾸로 늘였을 때 지면(y = 0)을 지나는 가상의 발사 전 시각이라는 뜻.

**주제**: Floor Field 구현 ② 동적 필드 D의 `update_D`(감쇠 + 확산)를 단계별로 직접 구현해 커밋. `/next FF` 안내 템플릿(단계 가이드·복붙용 시그니처·테스트 함수·커밋 명령)도 만들어 스킬에 연결.

### 구현한 것 (레포 floor-field-evacuation, 코드는 직접 작성)
- **감쇠**: `gone = rng.binomial(D, delta)`, `D_left = D - gone`. boson이 서로 독립이라 칸마다 이항분포 한 번. 확인: D=10 전 칸(합 39690)에서 합이 27843 (기대 27783 ± 91).
- **확산 수**: `moved = rng.binomial(D_left, alpha)`, `D_stay = D_left - moved`. 확인: moved 합 8376 (기대 8353 ± 76).
- **4방향 나누기**: `dirs = rng.multinomial(moved, [0.25] * 4)` → 모양 (63, 63, 4), 방향 합 == moved.
- **옮기기**: `for k in range(4)`에서 `di, dj = MOVES[k + 1]` (MOVES 0번은 제자리라 +1). `ok_nb = np.roll(walkable, (-di, -dj), axis=(0, 1))`로 이웃이 걸을 수 있는지, `sent = cnt * ok_nb`, `bounced = cnt - sent`(벽 쪽은 제자리), `arrive = np.roll(sent, (di, dj), axis=(0, 1))`. `new_D = D_stay.copy()`에 `bounced`, `arrive`를 더함.
- **확인**: 방 칸에만 D=10일 때 확산 후 합 26107 (감쇠 후 합과 같음, 개수 보존), 벽 칸 합 0, 최솟값 0.
- **규칙 결정**: 확산은 4방향 균등, 벽 쪽으로 가려던 boson은 제자리에 남는다 (논문 ②에 방향 규칙이 명시되지 않아 Claude가 제안, 구현으로 채택). 설계 노트 「구현 세부」에는 사용자가 직접 추가할 예정.
- 커밋 3개: `e47f7a7`(moved 계산), `3444bf6`(dirs), `b4d0c84`(확산 구현).

### 막혔던 점과 해결
- **`np.roll` 부호**: `ok_nb`를 `np.roll(walkable, di)`로 써서 위쪽 이웃 대신 아래쪽 이웃을 봄 → 벽 칸으로 30개가 도착하고 하단 24개가 막힘(출력 `1979 1955 24 1955 30`, 기대 `1979 1949 30 1949 0`). 이웃 값을 가져올 때(`ok_nb`)와 값을 보낼 때(`arrive`)는 밀기 방향이 반대. 벽 칸 도착량 0과 개수 보존으로 잡힘.
- **반복문 밖에서 방향 고정**: `di = -1`을 반복문 위에 두어 4방향이 모두 위쪽으로 계산됨 → `di, dj = MOVES[k + 1]`을 반복문 안으로.
- **`return D_left`**: 확산이 결과에 안 들어감 → `return new_D`.
- **커밋에 임시 `print`가 포함됨**: 아직 push 전이라 `git commit --amend --no-edit`으로 수정 (해시 `e3b3a9e` → `3444bf6`). push한 커밋에는 쓰면 안 됨.
