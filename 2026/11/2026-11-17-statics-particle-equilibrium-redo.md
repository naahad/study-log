# 2026-11-17 · 정역학 3.3 질점 평형 FP 다시 풀기 (/mech 복습)

**주제**: 11/13에 못 푼 Hibbeler 정역학 3.3 FP 4문제(F3-2·3-4·3-5·3-6)를 "틀린 지점"만 보고 혼자 다시 풀고 `/mech 복습 3.3`으로 채점.

## 결과
| 문제 | 11/13 | 11/17 다시 풀기 | 답 |
|---|---|---|---|
| F3-5 | 못 풂 (FBD에 C 무게 직접 넣음) | 정답 | m_A = 20 kg |
| F3-6 | 못 풂 (B·C 묶은 FBD, 미지수 3개) | 정답 | T_AB = 379 N, T_BC = 366 N, θ = 21.9°, T_CD = 395 N |
| F3-4 | 못 풂 (수평·수직 축) | 정답 | l0 = 0.283 m (Fs = 43.4 N) |
| F3-2 | 못 풂 (각도 → 길이) | 정답 | θ = 13.49°, L_ABC = 3.09 m |

4문제 모두 힌트 없이 정답 → 「역학 오답 노트」 3.3 복습 체크 완료.

## 핵심 개념 (다시 풀며 확인한 것)
1. **FBD에는 그 점에 직접 닿은 줄만**: 링 E에는 ED·EB 장력과 E에 매달린 W만. 도르래 건너편 C의 무게는 EB 장력 40(9.81) N으로 들어온다 (F3-5).
2. **점이 여러 개면 미지수 2개인 점부터 따로**: B(T_AB, T_BC) → 그 결과로 C(T_CD, θ). 두 식을 나누면 tanθ = 147.15/366.1 = 0.402 (F3-6).
3. **경사면은 면에 평행한 축**: ΣF(면 방향) = (4/5)Fs − 5(9.81) sin45° = 0 → 법선력 N이 식에서 빠짐. 스프링 방향은 0.3-0.4-0.5 삼각형으로 4/5 (F3-4).
4. **각도 → 길이는 아는 변과 삼각비**: 3.5 − 2(7.5 sinθ) = 0 → θ, 보의 반 길이 1.5 m로 L = 2(1.5/cosθ) (F3-2).

## 막혔던 점과 해결
- 없음. 11/13에 기록한 실수(sinθ에 단위 붙이기, 중간값 반올림 후 2배)도 재발하지 않음.
