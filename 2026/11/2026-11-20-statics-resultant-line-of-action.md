# 2026-11-20 · 정역학 4.8 힘·짝힘계의 추가 단순화 FP (/mech 4.8) · 동역학 12.7–12.8 n-t·극좌표

**주제**: Hibbeler 정역학 4.8 FP 6문제(F4-31~36)를 혼자 풀고 `/mech 4.8`로 채점. 힘계를 합력 하나로 바꾸고 그 작용선이 어디를 지나는지 구하는 절.

## 결과
6문제 중 맞음 3 · 불안 맞음 1 · 오답 2 (F4-32는 같은 날 스스로 고쳐 1.040 m).

| 문제 | 결과 | 답 (사용자 풀이 기준) |
|---|---|---|
| F4-31 | 맞음 | F_R = 1250 N 아래, O에서 d = 2 m |
| F4-32 | 오답 → 고침 | F_R = 184 N, θ = 62.5°, d = 1.040 m (처음 풀이는 0.704 m) |
| F4-33 | 맞음 | F_R = 16.3 kN, θ = 42.5°, A에서 d = 0.909 m |
| F4-34 | 맞음 | F_R = 11.2 kN, θ = 63.4°, A에서 y = 0.2 m |
| F4-35 | 불안 맞음 | F_R = 800 N 아래, x = 2.125 m, y = 4.5 m |
| F4-36 | 오답 | 부호 실수로 x, y 부호가 뒤바뀜 (다시 풀 예정) |

책 뒤 정답 사진 없이 Claude가 직접 푼 값으로 채점했다 (정답 확신: 중간).

## 핵심 개념
1. **합력 하나로 바꾸기**: F_R = ΣF를 구한 뒤, 같은 점에 대한 모멘트가 같게 되는 위치를 찾는다. 2차원은 (M_R)_O = ΣM_O = F_R,y · d (또는 F_R,x · y). 합력 하나로는 합모멘트를 만들 수 없으니 작용선을 옮긴다.
2. **보 위의 교점**: 보가 수평이면 수직 성분만 모멘트를 만들고(F4-31, F4-32, F4-33), 기둥 AB처럼 수직 부재면 수평 성분이 작용선의 높이 y를 정한다 (F4-34: F_R,x · y = 1 kN·m).
3. **평행 힘의 합력 작용 위치(3D 판, F4-35·36)**: 힘이 모두 z 방향이면 ΣM_x, ΣM_y로 x, y를 구한다. 벡터로는 r_P × F_R = ΣM_O를 풀어 성분을 맞춘다.
4. **합력의 작용선은 연장선이다**: 반대 방향 힘이 섞이면 작용선이 물체 밖(y = 4.5 m, 판 폭 밖)에 있어도 된다.

## 막혔던 점과 해결
- F4-32: 50 N 힘의 x = 3 m 지점 모멘트에서 모멘트 팔과 맞는 성분을 잘못 골랐다. 사용자 판단은 개념이 아니라 순간 실수, 같은 날 고침 (1.040 m). 내일 `재풀이\`로 확인.
- F4-35: y = 4.5 m가 판 밖이라 "물체 밖에서 작용?" 하고 `?`를 달았다 → 작용선이 연장선이라 문제없음.
- F4-36: 외적 전개 후 양변을 i, j 성분으로 맞출 때 i×k = -j, j×k = i 부호 변환을 잘못 처리했다. (사진의 + 400 표시는 썼다 지운 흔적을 Claude가 잘못 읽은 것으로 사용자가 정정.) 3D 외적 부호 실수가 4.4부터 반복됨.

## 이어서 (17:40)

**주제**: 동역학 12.7–12.8 n-t 좌표·원통(극) 좌표 teach (`/univ teach`). 중간에 미분 기초와 벡터 표기로 한 단계 내려갔다.

### 핵심 개념
1. **n-t 좌표**: 속도는 항상 접선이라 v⃗ = v ê_t. 가속도는 a⃗ = a_t ê_t + a_n ê_n, a_t = dv/dt(속력 변화), a_n = v²/ρ(방향 변화, 항상 곡률중심 쪽). 속력이 일정해도 휘면 a_n이 생긴다 (ρ = 100 m, v = 20 m/s → a_n = 4 m/s²).
2. **극좌표 단위벡터**: ê_r = cosθ î + sinθ ĵ, ê_θ = -sinθ î + cosθ ĵ. 시간 미분은 dê_r/dt = θ̇ ê_θ, dê_θ/dt = -θ̇ ê_r (연쇄법칙).
3. **극좌표 속도·가속도**: v⃗ = ṙ ê_r + r θ̇ ê_θ, a⃗ = (r̈ - r θ̇²) ê_r + (r θ̈ + 2 ṙ θ̇) ê_θ. 2ṙθ̇는 r 변화에 따른 v_θ 크기 변화(ṙθ̇)와 v_r ê_r의 회전(ṙθ̇)이 각각 기여한 것.
4. **원운동 확인**: r = 2 m 일정, θ̇ = 3 rad/s → v⃗ = 6 ê_θ, a⃗ = -18 ê_r (= a_n = v²/ρ = 18, 중심 방향). ṙ = -1이면 v⃗ = -1 ê_r + 6 ê_θ, a⃗ = -18 ê_r - 6 ê_θ.
5. **좌표 고르기**: r, θ로 주어지면 극좌표, 경로 모양(ρ)·속력·a_t로 주어지면 n-t.

### 막혔던 점과 해결
- 극좌표 단위벡터의 시간 미분 단계부터 따라가지 못함 → dot 표기, 곱의 미분, 연쇄법칙을 한 단계 내려가 설명. d(sinθ)/dt = cosθ·θ̇ 계산은 정답.
- 벡터와 스칼라 표기가 섞여 헷갈림 → 벡터는 화살표(v⃗), 단위벡터는 모자(ê_r), 스칼라는 평문으로 구분.
- 곱의 미분에서 ΔA가 0으로 가는데 왜 한 영역만 사라지나 → Δt로 나눈 뒤 비교: a·c 영역은 한 변이 Δt와 약분되어 남고, 구석 영역은 두 변이 모두 작아 사라짐.
- a_r과 a_θ 중 ṙ가 들어 있는 식을 놓쳐 부호가 바뀌는 쪽을 틀림 → 식에서 ṙ 위치를 찾으니 정답 (ṙ가 a_θ에만 있음).
