# 2026-11-23 · 정역학 5.4 2력·3력 부재, 강체 평형 FP (/mech 5.4)

**주제**: Hibbeler 정역학 5.4 FP 6문제(F5-1~6)를 혼자 풀고 `/mech 5.4`로 채점. 지점 반력의 방향을 정하고 2차원 강체의 평형식(ΣFx, ΣFy, ΣM)으로 푸는 절. 틀린 F5-4·F5-5·F5-6은 해설과 재풀이까지 했다.

## 결과
6문제 중 맞음 3 · 오답 2 · 못 풂 1 (오답·못 풂은 모두 같은 날 해설 후 고침).

| 문제 | 결과 | 답 (사용자 풀이 기준) |
|---|---|---|
| F5-1 | 맞음 | A_x = 3 kN 왼쪽, A_y = 0.5 kN 위, B_y = 3.5 kN 위 |
| F5-2 | 맞음 | A_x = 8 kN 왼쪽, A_y = 4 kN 아래, F_C = 11.314 kN |
| F5-3 | 맞음 | A_x = 3.536 kN 왼쪽, A_y = 5.488 kN, B_y = 8.047 kN |
| F5-4 | 오답 | 식은 모두 맞고 합산만 틀림: A_y 400 N → 800 N, M_A 3.090 → 3.90 kN·m (A_x = 346 N은 맞음) |
| F5-5 | 오답 → 고침 | N_C = 151.709 N, T = 136.019 N, A_y = 134.191 N → 재풀이 T = 78.530 N, A_y = 93.541 N |
| F5-6 | 못 풂 → 해설 후 맞음 | N_C = 433.013 N, N_B = 327.350 N, N_A = 577.350 N |

책 뒤 정답 사진이 없어 F5-4·F5-5·F5-6의 정답은 Claude가 그림에서 직접 계산한 값이다 (정답 확신: 중간).

## 핵심 개념
1. **지점 반력은 종류별 방향부터 정한다**: 롤러·매끄러운 접촉·peg는 접촉면에 수직인 힘 1개, 줄은 줄 방향 장력, 핀은 성분 2개, 고정 지지는 힘 성분 2개와 모멘트.
2. **홈에 낀 매끄러운 peg (F5-5)**: 반력은 막대에 수직인 N_C 하나다. 막대가 수평에서 30°면 N_C는 수평에서 60°이고 x 성분 N_C sin30°, y 성분 N_C cos30°. 그림에 각을 표시하고 구한다.
3. **모멘트 점 고르기**: 미지수 두 개의 작용선이 만나는 점을 잡으면 식 하나에 미지수 하나가 남는다 (F5-5의 A, F5-6의 C).
4. **수직 힘의 팔은 수평 거리**: 막대를 따라 잰 거리가 아니다 (F5-6: 0.2 m에 cos30°). 막대에 수직인 힘의 팔은 막대 위 거리 자체다.
5. **A·B가 수직이면 ΣFx로 N_C가 바로 나온다 (F5-6)**: ΣFx = 0에는 250 N의 수평 성분과 N_C의 x 성분만 있다.
6. **작용선 위 어느 점에서든 모멘트를 계산해도 된다 (전달성, F5-2)**: 2력 부재 DC가 C에 주는 힘을 D에서 작용하는 것으로 보고 A에 대한 모멘트를 구해도 같다 (F_x의 팔 1.5 m, F_y의 팔 0).
7. **합산 계산**: 식을 세운 뒤 항별 값을 따로 적고 더하고, 구한 값을 ΣF에 다시 넣어 0이 되는지 검산한다 (F5-4).

## 막혔던 점과 해결
- F5-5: C를 C_x, C_y 두 성분으로 둬 미지수가 4개가 되어 중단. N_C 하나로 두고 ΣM_A부터 풀어 N_C = 151.709 N까지는 맞음. 이어 ΣFx, ΣFy에서 N_C의 sin과 cos을 바꿔 T = 136.019 N, A_y = 134.191 N을 얻음 → 막대에 수직 방향의 각이 수평에서 60°임을 그림에 표시하고 다시 풀어 T = 78.530 N, A_y = 93.541 N.
- F5-6: A에 A_x, A_y 두 성분을 두고 C의 힘을 쓰지 않았으며 B의 팔을 막대 방향 0.2 m로 썼다 → A는 수직(아래), B는 수직(위), C는 막대에 수직으로 두고 ΣFy, ΣM_C 식을 맞게 세움. 빠진 ΣFx를 더해 풀었다.
- F5-4: 식은 맞고 ΣFy에서 A_y = 400 N(정답 800 N), ΣM_A에서 3.090(정답 3.90 kN·m)으로 합산 실수 (사용자 확인: 계산 실수).
- F5-2: Claude가 처음 "팔 오류, 우연히 상쇄"로 판정했으나 사용자 풀이가 맞았다 (전달성). 오기록 행은 삭제.
